# Kenya Health Intelligence & Resource Prioritisation Platform

A county-level data science and decision-support project for mapping health vulnerability, identifying spatial inequalities, and supporting evidence-based health resource prioritisation across Kenya.

## Project Aim

To develop a county-level health intelligence framework that integrates health, socioeconomic, environmental, and healthcare-access indicators across Kenya's 47 counties.

## Core Components

- Data integration and cleaning
- County Health Vulnerability Index
- Spatial analysis and hotspot detection
- Predictive and explanatory modelling
- Health resource allocation optimisation
- Interactive dashboard
- Technical report and reproducible workflow

## Geographic Scope

Kenya — 47 counties
